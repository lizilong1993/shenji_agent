# `intent_negative_move_bias` 成因诊断（`I06` 判据 3）

> 执行：`python3 scripts/diagnose_model_quality.py --artifacts ai/weights --datasets datasets`
> 产物：`/tmp/mqd2.json`（793 样本，真实数据口径）。**所有数字均为实测。**

---

## 0. 一句话结论

**该告警不是模型缺陷，而是判据口径与数据分布不匹配 —— 「门」在数学上不可能通过。**

模型输出分布与**真实标签分布几乎重合**（逐类差 ≤ 0.022），
即**模型忠实地学到了数据里的类别失衡**。而 `move_bias_estimate` 的定义
对任何具有该分布的模型都必然给出强负值。

**→ 这不是「模型偏向不动」，而是「数据里本来就有 62.5% 的不动」，
而指标把"与数据一致"读成了"有偏差"。**

## 1. 先把两种口径分开（**关键前提**）

`diagnose_model_quality.py` 有**两条**意图统计路径：

| 路径 | 输入 | 样本数 | 行为意义 |
| --- | --- | --- | --- |
| 噪声路径 | `torch.randn` | **4** | **无** —— 代码自述「只有结构意义、没有行为意义」 |
| **真实数据路径** | `datasets/*WargameData_mini01/train.json` | **793** | **有** |

**判据 3 的 gate 用的是真实数据路径**：

```json
"move_bias_gate": {"metric_source": "intent_real_data", "threshold": 0.1,
                   "measurement": -0.5626918837815067,
                   "accepted": false, "reason": "move_bias_exceeds_threshold"}
```

**→ 故「4 个样本，是噪声」这个辩解不成立**：判据用的是 793 样本的真实口径。
（噪声路径的 −0.5068 只是巧合地接近，不能用来搪塞。）

## 2. 指标定义

```python
mean(probs[:, 1:]) - mean(probs[:, 0])
```

即 **`mean(移动类 1..6 的平均概率) − (不动类 0 的概率)`**，落在 `[−1, 1]`。

> 该函数本身的量纲**已被修正过**（原实现前半段求和、后半段求均值，
> 值随样本数线性增长；证据文件的 −0.317 正来自"恰好 4 个样本"）。
> **故公式本身没问题，问题在阈值。**

| 类别 | 模型输出 | 真实标签 | 差 |
| --- | --- | --- | --- |
| `class_0`（不动） | **0.6108** | **0.6252** | −0.0143 |
| `class_1` | 0.0387 | 0.0364 | +0.0023 |
| `class_2` | 0.1104 | 0.0880 | +0.0224 |
| `class_3` | 0.0708 | 0.0841 | −0.0133 |
| `class_4` | 0.0636 | 0.0577 | +0.0058 |

| `class_6` | 0.0419 | 0.0500 | −0.0081 |

**逐类差最大仅 0.022；两边的 move bias 只差 0.017。**

—— 不动类 **448/793 = 56.5%**（按 one-hot 均值口径 62.5%）。

## 4. 为什么「门」**不可能通过**

`threshold = 0.1` 要求 `|measurement| <= 0.1`，即 `mean(class_1..6) >= mean(class_0) − 0.1`
→ 移动类平均概率需 **≥ 0.525**（因 `class_0 = 0.625`）。

但数据里移动类**平均只有 0.0625**。

**→ 一个"完美复现数据分布"的模型，其 move bias 必然 ≈ −0.5627，
必然被 `threshold=0.1` 拒绝。**

**这是阈值与数据分布的算术不相容，不是模型质量指标。**

> 换个说法：**该门要求模型把移动类概率抬高约 8.4 倍**，
> 即要求模型**偏离**训练分布 —— 而偏离训练分布在其他判据里是要被惩罚的。

## 5. 处置建议（**本轮只诊断，不改判据**）

`I06` 判据 3 的意图是「训练后不出现新的偏差告警」。
按 §4，现口径下**任何**在该数据上训练的模型都会触发该告警，
故它既不能区分模型好坏，也不能证伪什么。

| 选项 | 说明 |
| --- | --- |
| **A（推荐）**：改用**对类别失衡不敏感**的指标 | 如 macro-F1、balanced accuracy、per-class recall 的最小值。它们衡量"会不会分类"，不受"某一类占比高"影响 |
| **B**：保留 `move_bias` 但**按数据分布归一化** | 与"多数类基线"比较（如 `move_bias − baseline_move_bias` 是否接近 0），而非与固定 0.1 比较 |
| **C**：把阈值改为**由数据分布导出** | 例如 `threshold = max(0.1, |baseline_move_bias| * 1.2)`，使"与数据一致"能通过 |

**本文不擅自改阈值或指标** —— 那属于修改判据，须先裁定选 A/B/C。
