# P0.1 空间权威统一：envpack 导航场（2026-10-22）

> 结论先行：envpack 场景（`taiwan_landing` + `anping_v2c`，1440 tick × 30 s）地面直瞄从
> **0 → 23 次**，事件 252 → 338，毁伤 9 → 14，"规划—阻塞—再规划"循环消失；步进 p50
> **574 ms → 126 ms**。全部 205 项测试通过（含 14 项导航场测试）。

## 1. 问题（ARCHITECTURE_GAPS G1）

规划在 2 km 基础地图格上（`plan_grid=基础图格`），而 `EnvPackEnvironment` 的水面/建筑是
亚单元 OSM 几何；50 m 子步判阻塞后重新规划，路线反复落在潟湖/水面上，形成死循环。
同一场景中规划、裁决、运动读不同来源，是"能走不能打/能打走不过去"的根因。

## 2. 方案

### 2.1 导航场（`mobility/nav_field.py`）

从 envpack 直接生成规则经纬格网（默认 30 m，超过 25 万单元时自动放大）：

| 图层 | 来源 | 用途 |
|---|---|---|
| 高程/坡度 | terrain 双线性 + 栅格梯度 | 坡度通行与速度 |
| 水深 | water 多边形 + bathymetry（含基础图回退） | 涉水/两栖/舰艇 |
| 地表 | landcover 多边形（含基础图回退） | 地表速度因子 |
| 建筑 | **真实 OSM 足迹**（不含基础图"城区=建筑"假体） | 移动障碍 |
| 道路 | 路网逐边栅格化 | 道路加速、桥隧限重/限高/限宽 |

- 每个平台按掩码判定通行与速度（与 `mobility/passability` 同语义），首次使用时惰性生成
  并缓存；视图缓存到 envpack 目录 `nav_cache_30m.pkl`（按图层 mtime/size 失效）。
- 包内以导航场为**唯一权威**：规划、子步碰撞、速度因子读同一栅格。

### 2.2 两级规划

- 包内两端：直接细网格 A*（8 邻接、禁止斜穿墙角、LOS 平滑）。
- 跨包边界：先以 `GridPlanner` 生成全局粗路线，再沿粗路线在包内区段扫描首/末可通行采样点，
  用细 A* 替换该区段（`NavField.plan_hybrid`）；包外保持基础图权威。这对应"粗 500 m/2 km
  全局 + 细 30 m 局部"的两级结构（本包仅 5×5.6 km，细网格全包一次 A* 已足够便宜）。
- 目标点在建筑内时在 ≤2 格内吸附，保证偏移后仍落在目标规则格。

### 2.3 运动与装配

- `sim.motion.integrate(..., nav=)`：包内子步用导航场掩码（子步距 0.7×分辨率），包外用环境谓词。
- `World.plan_route(entity, goal)`：地面/两栖走 `NavField.plan_hybrid`，其余（海/空）保持粗规划；
  `_apply_orders`、阻塞重规划、`run_geo_demo` 统一走该入口。下船落点若落在建筑/水面内，
  用导航场吸附到最近可通行格（≤8 格）。
- 开关：`engine.nav_enabled`（默认 true）、`engine.nav_res_m`（默认 30）。无 envpack 时 `nav=None`，
  行为与之前完全一致（金标准/哈希不受影响）。

## 3. 验收（P6 envpack 场景，seed 20261021，1440 tick × 30 s）

| 指标 | 改前（d3ec3e8） | 改后 |
|---|---|---|
| 地面直瞄 | 0 | **23** |
| 事件总数 | 252 | 338 |
| 毁伤 | 9 | 14 |
| 下船 / 目标 | 3 / 1 | 3 / 1 |
| 步进 p50 / p95 | 574 ms / — | **126–128 ms / 243–245 ms** |
| 运行时长 | 约 14–30 min | 218 s |

说明：首版细化（未含桥面/退化路线修正）曾达 66 次直瞄；二轮修正后单位可经桥跨越运河、
接触线与交战节奏改变，直瞄为 23 次，仍满足验收（>0、无循环）。三次复跑均为 338 事件 /
23 直瞄，结果稳定。

规划/阻塞诊断：本次运行 `event_types` 中无 `move_failed`/`stack_blocked`；A* 与快照同序确定
（`test_plan_is_deterministic`）；导航场构建 8.3 s（首次）/ 0 s（缓存）。

子步阻塞归因（1440 tick，插桩统计）：包内导航场判定失败 **0 次**（规划与运动完全一致）；
包外基础图判定失败 3059 次，全部集中在 `land:2021`（台南防空导弹排）与 `amphibious:1032`
（两栖步兵）——前者被派往跨海目标、后者在包外基础图 2 km 水域边缘，属包外粗权威与
海空简化的剩余问题（P2），与本包内的"规划-阻塞"循环无关。

## 4. 测试

- 新增 `tests/test_nav_field.py`（14 项）：水/建筑绕行、建筑吸附、确定性、运动一致性、
  混合规划包内细化、速度因子、envpack 连通性（最大连通分量 >90%），以及评审补充的回归：
  30 m 默认分辨率下逐段稠密可通行、起点在建筑格内的脱困、不可达（全墙）返回 None、
  桥面跨水可通行、起点=终点。
- 全量：**205 passed, 3 skipped**。
- 无 envpack 回归对拍：基础地图 `taiwan_landing` 与纯净 `91a71e0` worktree 结果完全一致
  （366 事件、直瞄 40、毁伤 13、p50 7.7 ms），证明非 envpack 路径未受影响。

## 4.1 独立评审修正（2026-10-22）

独立 reviewer 复核后修复以下问题并补回归测试：

- **规划自阻塞（blocker）**：A* 顶点不再按 45 m 抽稀；平滑段改用精确格网超覆盖
  （Amanatides-Woo）判定所穿过的每个栅格，杜绝"平滑后切过建筑角"。
- **失败回退（major）**：包内两端规划失败时不再退回粗规划（返回 None，走 `move_failed`）；
  跨包回退前必须通过导航场对整条路线的精确校验。
- **接缝残留（major）**：细化后的整条路线（含粗路线前缀/后缀的包内部分）做超覆盖校验，
  不通过则判失败，不再保留"包内不可通行段"。
- **起点在阻塞格（major）**：运动层增加脱困模式（起点格不可通行时以 20% 最高速向路线首点
  行驶，逐子步检查），避免单位永久冻结；起始吸附半径 3→5 格。
- **桥隧（major）**：`bridge`/`tunnel` 边栅格化为桥面，跨水面可通行（限重/限高/限宽仍生效），
  桥面按最大速行驶。
- **健壮性**：起点=终点、res 下限、单行/单列坡度、缓存签名纳入回退底图、缓存维度校验与
  更宽异常捕获、非机动车边不写限值、清理死代码。
- **二次复核补充**：起点=终点的退化路线也做超覆盖校验（不通返回 None，避免静默循环）；
  包内 landcover 非水面时不再采用基础图 2 km 回退水深（修复 757 格含 461 个道路格被误判为
  20 m 水深的伪阻塞）；桥面仅对机动车道边生成并做十字加厚（斜桥可通行），桥面优先于建筑
  足迹判定；缓存文件名按 0.1 m 分辨率区分、签名用 `st_mtime_ns`；`World(nav=...)` 移到参数表尾。
- **保留**：路线限速已含一次地形因子、运动再乘一次（与既有 `GridPlanner` 对齐，属已知
  语义问题，不在 P0.1 改）；导航场仅用于地面/两栖，海空仍走粗规划（P2）；`_refine` 端点
  不可通行时返回 None 而非沿粗路线扫描回退（宁可不走，不静默循环）。

## 5. 限制与后续

- 包外仍是基础图粗几何；envpack 即该区域权威（符合"按区域单一权威"）。
- 建筑作为整格障碍（30 m 精度），尚无车宽/转弯半径；OBB 碰撞与运动学属 P0.2。
- 水面/潜艇仍走粗规划（P2 海空动力学一起做）。
- 道路栅格 1 格宽，桥隧限值只在栅格化覆盖到的单元生效；车道/单行/限速属 P1 运动学规划。

## 6. 复现

```bash
cd situation3d
python3 scripts/run_geo_demo.py --case taiwan_landing \
    --envpack envpacks/anping_v2c --ticks 1440 --dt 30 --out /tmp/tw_p0_1

```
