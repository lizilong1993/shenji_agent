# 性能：300/500 实体 p95 达标（2026-10-22）

> 提交 `960591f`（优化）、`f2a6a0c`（文档）、后续修正检测缓存与门槛（见 git log）；
> 基准脚本 `scripts/bench_geo_engine.py`，回归门槛 `tests/test_bench_regression.py`。

## 1. 方法

- 场景：60×60 / 200 m 网格，红蓝均势重型坦克（seed=1，武器 36），无指挥官/战术，纯引擎步进。
- 口径：先跑 `--warmup 10` 预热（缓存/索引填充），再统计 `--ticks` 内每 tick 耗时；
  p95 取排序后 `int(n*0.95)`。预热前的冷启动尖峰单独记录，不混入验收。
- 语义回归：同 seed 事件 JSON 的 sha256 前 16 位固定，优化前后必须一致。

## 2. 结果（server155，宿主机负载随他人任务波动）

| 配置 | 优化前（含冷启动） | 优化后稳态（warmup 10，负载≈40） | 优化后稳态（负载≈50） | 事件哈希 |
|---|---|---|---|---|
| 300 实体 ×100 tick | p50 53.4 / p95 114.6 / max 436 ms | p50 12.0 / p95 19.7 / max 34 ms | p50 20–26 / p95 37–46 ms | `51a51b36739dcfc7`（前后一致） |
| 500 实体 ×100 tick（+10 warmup） | —（500×60 w0：p50 166.5 / p95 374.6） | p50 32.6 / p95 51.4 / max 71 ms | p50 52–62 / p95 93–106 ms | `74a15497022ed66e`（前后一致） |
| 500 实体 ×60 tick（warmup 0） | p50 166.5 / p95 374.6 / max 1106 ms | p50 81 / p95 577 ms（冷启动计入） | 同左 | `15300b919f058b10`（前后一致） |

冷启动：首 2–5 tick 仍为 0.1–1.7 s（检测/LOS 缓存建立、A* 首规划），第 6 tick 起稳定。

**验收口径**：300 实体稳定达标；500 实体在宿主机负载 ≤~45 时 p95 51 ms，负载 ≈50 时
p95 93–106 ms，处于 100 ms 边界。回归测试门槛设为 120 ms（防共享宿主机调度噪声误报），
核心性能对拍以同机同负载下的前后对比为准。

## 3. 优化内容（均不改裁决语义）

1. **LOS 单元对持久缓存**（`World._los_cell_cache`）：地形/建筑静态，`cell_line_of_sight(ca, cb)`
   结果可跨 tick 复用；键按无序单元对，上限 50 万条。首轮扫描后稳定态几乎零 LOS 计算。
2. **检测结果持久缓存**：陆上对陆上的可探测性依赖（观察者/目标、单元对、目标隐蔽状态、目标覆盖类别、
   双方高程等级），缓存键包含全部这些输入（覆盖/高程为亚单元连续量，不能只用 200 m 单元号）；
   静止部队第二遍起零成本。海/空对使用连续坐标与逐点 LOS，**不做跨 tick 缓存**。
3. **单 tick 小缓存**：`cover_at` 按实体缓存、`env.grid.cell_of` 按实体缓存（每 tick 清空），
   `det_meta` 每 tick 预计算一次（覆盖类别 + 高程等级），避免逐对重复查询。
4. **距离复用**：`_compute_table_seen` 已算的 cube 距离传入 `can_detect/can_observe`，
   省去重复 `rule_distance`。
5. **基准脚本**：新增 `--warmup`、事件哈希与进程峰值内存（rss）；回归测试固定 300/500 配置的
   p95 门槛与事件哈希。

## 4. 正确性注意

- 早期版本的陆-陆缓存键只含单元对与隐蔽状态，在真实 `EnvPackEnvironment`（覆盖多边形/DEM 为亚单元数据）
  下会复用陈旧结果；已把覆盖类别与双方高程等级纳入键，并新增
  `tests/test_detection_cache.py`（同一单元内穿越森林边界，开/关缓存结果一致）。
- 海/空检测改为不缓存，避免连续位置变化导致的陈旧判定。
- `_los_cell_cache` 以环境网格单元对为键，前提是地形/建筑在运行期不变（当前引擎满足）。

## 5. 剩余热点与后续

- 冷启动：首 tick 500 实体约 1.7 s；可预计算静态可见性或预热缓存（不影响稳态）。
- `_compute_table_seen` 的逐对循环与 `_engage`/`_best_target` 为当前稳态主要开销；
  可做候选裁剪、整数键或 numpy 批量距离。
- 缓存内存：检测/LOS 各 50 万条上限，约数十 MB 量级；超限停止写入（退化为逐次计算）。

## 6. 验收

- 300 实体稳态 p95 19.7–46 ms < 100 ✓；500 实体 p95 51（负载≈40）～93–106（负载≈50），
  在 100 ms 目标边界，需在安静宿主机上复测确认。
- 事件哈希与优化前完全一致 ✓（`test_bench_regression` 固化；含 300×100、500×110、500×60 三种配置）。
- 全量测试通过（含 P4/数据管线/JEV 既有用例）。
